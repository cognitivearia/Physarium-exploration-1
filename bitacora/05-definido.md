# 05 — La figura se queda, y el estado cambia

Mari señaló el proyecto physarum-36p de Bleuje por el resultado: figuras muy definidas, y poder pasar de una a otra. No copiamos ese código ni su lista de parámetros. La licencia no lo permite. Lo que sí tomamos es la diferencia que explica por qué antes se perdían las líneas.

Antes dibujábamos el olor. El olor tiene que apagarse, si no el moho no puede cambiar de conducta. Por eso la red se borraba y el estado nuevo casi no se notaba.

Ahora hay dos capas. El olor sirve para que cada partícula decida hacia dónde girar, y se apaga. El dibujo es otra cosa: solo marca donde están las partículas, con un borde duro. Mientras siguen la vena, la vena se queda negra. Si cambias de estado (flechas, o 1–4), el olor se limpia, los rumbos se sueltan y en un momento nace la figura nueva.

Hay unas 42000 partículas de moho. Los recortes bajaron, para que el cálculo alcance y la hoja no se llene de papeles.

Los cuatro estados, con números de esta pieza: red (piedras), nudos (grieta fina), cordones (muros gordos), ramas (venas largas que se cruzan).

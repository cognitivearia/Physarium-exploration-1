# 07 — Los agudos hacen llorar la vena

Mari pidió probar los agudos, y que el efecto se note de más en la vena: un llanto nervioso.

El volumen sigue engrosando el trazo. Los agudos son otra cosa. Son las frecuencias altas: charles, ruido, una voz filosa. Cuando suben, la vena tiembla, se abre y se corta. Cuando bajan, vuelve a ser la red quieta. El bajo no dispara ese temblor.

La lectura fuerte se pasó. Arriba hay un slider, magnitud de 0 a 100. 0 apaga el llanto. 100 es el temblor máximo. El número grande al lado del slider es el que Mari puede decir para dejarlo fijo.

`L` apaga las dos cosas juntas. La mano y el estado siguen mandando.
